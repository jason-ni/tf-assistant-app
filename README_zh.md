# tf-assistant

**tf-assistant** 是一款 macOS 桌面应用，集 AI 编程智能体、语音转录、截图 OCR、PDF 解析、翻译和字幕编辑于一体，全部由本地 AI 模型驱动。

## 功能特性

### AI 编程智能体
基于 opencode 编码智能体的智能体开发环境（ADE），位于独立的 Agent 窗口中。

- 在代码仓库内与 AI 智能体对话：支持文本、推理、工具调用、待办列表、图片、计划评审等多类型消息的流式渲染
- Helmor 风格输入框：模型选择器（按提供商分组）、推理强度选择、智能体选择（build / plan / 自定义）及实时更新的上下文用量环（主题自适应）
- 仓库与工作区模型：可添加本地仓库或从 URL 克隆，并提供四种工作区模式——`worktree`（git worktree 检出）、`local`（原地操作）、`chat`（临时目录）、`non_git`（普通目录）
- 右侧文件浏览器：文件系统监听自动刷新的目录树、Git 状态徽标、全工作区 ripgrep 文件搜索、只读预览（支持图片/音视频内联预览）及完整文件操作（新建、重命名、删除、显示）
- 内联 Git 面板：分支切换、领先/落后与已暂存/未暂存状态汇总、逐文件工作树差异及最近提交
- 内嵌可折叠终端面板：每个工作区多个普通 shell 终端，折叠后保持运行
- 独立文件编辑器窗口，多文件标签（跟随文件系统变化自动刷新）：代码用 Monaco，Markdown 用 Milkdown 所见即所得，可选 Vim 模式，支持字号/字族与查找替换
- 编辑器 LSP 代码导航：跳转到定义（F12 / Cmd+点击）、内联查看定义（Alt+点击）、查找所有引用（Shift+F12）、悬停显示类型签名与文档、文件内与工作区符号搜索、前进/后退跳转历史，以及 Vim `gd`/`du` 快捷键
- 安全优先的权限模型：每条 bash 命令都会询问、敏感文件读取会询问、`plan` 智能体保持只读，可持久化“始终允许”规则并支持自动授权开关
- 交互式问题卡片：分步回答智能体的提问，支持选项、自由文本以及拒绝/提交
- 斜杠命令发现（`/`）、消息撤销/恢复、超长会话虚拟化渲染及心跳异常恢复
- 基于全局 opencode 配置的按工作区 MCP 配置界面（新增服务器默认禁用）

### 语音转文字
- 转录音频文件（WAV、MP3、FLAC、M4A、AAC 等格式）
- 下载并转录 YouTube 视频
- 实时系统音频采集，支持实时字幕
- 说话人分离（区分谁在何时说话）
- 多种转录模式：语音活动检测、固定窗口、完整说话人分离
- 导出字幕为 SRT 格式

### AI 听写
- 在任何应用中听写：说话后转录文字实时插入到前台应用，由本地 AI 模型驱动
- 基于语音活动检测的实时识别，支持按住说话（Shift）与按键切换（PTT）两种模式
- 可选择任意麦克风输入设备；支持按需静音/取消静音
- 插入前可进行 LLM 润色：raw、light、structured、formal、translate 五种模式，另支持自定义模式
- 热词与工作语言上下文，用于纠正误识别
- 内建中/英文提示词，可编辑并一键恢复默认
- 兼容 OpenAI 的提供商，支持按提供商禁用思考并可选走代理

### 截图与 OCR
- 通过全局快捷键截取屏幕区域
- 可配置检测与识别模型进行文字识别
- 文档版面分析、方向检测、公式识别、表格提取
- 支持端到端 Ovis OCR2 模型，进行端到端文档 OCR 处理（直接输出 Markdown，可选不同量化变体）
- 新增端到端 OCR 引擎 dots-mocr（MXFP4），可用于截图与 PDF 的 OCR
- Markdown 直出查看器：视觉区域框选叠加、原始 Markdown 渲染（公式、代码、表格）、整页翻译、复制为 Markdown
- 在图像上叠加显示识别结果与边界框

### PDF
- 从托盘菜单打开并查看本地 PDF 文件，使用独立窗口
- 功能完整的阅读器：缩放/适配、文本搜索、页面缩略图、文档大纲、旋转、全屏及双页展开
- 将任意 PDF 提取为 Markdown，供阅读或发送给智能体；内嵌图片通过惰性、按内容寻址的图片协议内联渲染
- 以三种模式对 PDF 进行 OCR——`text`（使用已有文本层）、`auto`、`ocr`（完整重新识别）——作为后台任务运行，支持逐页持久化与全文搜索

### Snap Translate（截图翻译）
- 一键快捷键工作流：截图 → OCR → 翻译
- 支持 38+ 种目标语言

### 翻译
- 内建本地翻译引擎
- 实时翻译直播字幕
- 可配置目标语言
- 开机自动启动翻译服务

### 字幕编辑器
- 创建与管理字幕项目
- 多轨道支持
- 音频波形可视化与视频预览
- 完整的片段编辑：添加、拆分、合并、排序、批量偏移
- 撤销/重做
- 对指定片段重新转录

### 模型管理
- 从内建目录浏览、下载和删除 AI 模型
- 模型分组：ASR、OCR、翻译、VAD
- 下载进度追踪
- 下载源偏好设置（HuggingFace / ModelScope）

### 任务监控
- 查看所有处理任务的状态、进度和产物
- 按状态筛选（排队中 / 运行中 / 已完成 / 失败 / 已取消）
- 取消、重试或删除任务

### HTTP 服务器
- 提供语音转录和翻译的 REST API
- 可配置主机、端口和默认模型参数

### 个性化设置
- 可自定义全局快捷键（截图、截图翻译、音频采集）
- 代理设置
- 外部工具路径配置（yt-dlp、ffmpeg、deno）
- OCR 模型与语言偏好
- 界面语言选择（国际化）
- 浅色/深色主题

## 系统要求

- macOS Apple Silicon

## 安装

从 [Releases](https://github.com/jason-ni/tf-assistant-app/releases) 页面下载最新版本。

## 快速开始

1. 启动应用
2. 按照初始设置向导配置数据目录和工具路径
3. 在设置 → 模型中下载所需模型
4. 开始转录、截图或翻译
