# tf-assistant

**tf-assistant** 是一款 macOS 桌面应用，集语音转录、截图 OCR、翻译和字幕编辑于一体，全部由本地 AI 模型驱动。

## 功能特性

### 语音转文字
- 转录音频文件（WAV、MP3、FLAC、M4A、AAC 等格式）
- 下载并转录 YouTube 视频
- 实时系统音频采集，支持实时字幕
- 说话人分离（区分谁在何时说话）
- 多种转录模式：语音活动检测、固定窗口、完整说话人分离
- 导出字幕为 SRT 格式

### AI 听写
- 说话即可实时转录为文字，由本地 AI 模型驱动
- 可在应用内直接听写笔记、消息或文档

### 截图与 OCR
- 通过全局快捷键截取屏幕区域
- 可配置检测与识别模型进行文字识别
- 文档版面分析、方向检测、公式识别、表格提取
- 支持端到端 Ovis OCR2 模型，进行端到端文档 OCR 处理
- 在图像上叠加显示识别结果与边界框

### Snap Translate（截图翻译）
- 一键快捷键工作流：截图 → OCR → 翻译
- 支持 38+ 种目标语言

### 翻译
- 内建本地翻译引擎
- 实时翻译直播字幕
- 可配置目标语言
- 开机自动启动翻译服务

### 字幕编辑器
- 创建与管理字幕项目
- 多轨道支持
- 音频波形可视化与视频预览
- 完整的片段编辑：添加、拆分、合并、排序、批量偏移
- 撤销/重做
- 对指定片段重新转录

### 模型管理
- 从内建目录浏览、下载和删除 AI 模型
- 模型分组：ASR、OCR、翻译、VAD
- 下载进度追踪
- 下载源偏好设置（HuggingFace / ModelScope）

### 任务监控
- 查看所有处理任务的状态、进度和产物
- 按状态筛选（排队中 / 运行中 / 已完成 / 失败 / 已取消）
- 取消、重试或删除任务

### HTTP 服务器
- 提供语音转录和翻译的 REST API
- 可配置主机、端口和默认模型参数

### 个性化设置
- 可自定义全局快捷键（截图、截图翻译、音频采集）
- 代理设置
- 外部工具路径配置（yt-dlp、ffmpeg、deno）
- OCR 模型与语言偏好
- 界面语言选择（国际化）
- 浅色/深色主题

## 系统要求

- macOS Apple Silicon

## 安装

从 [Releases](https://github.com/anomalyco/tf-assistant/releases) 页面下载最新版本。

## 快速开始

1. 启动应用
2. 按照初始设置向导配置数据目录和工具路径
3. 在设置 → 模型中下载所需模型
4. 开始转录、截图或翻译
